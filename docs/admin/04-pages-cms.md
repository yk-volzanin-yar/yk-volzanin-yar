# 10. Pages CMS: настройка и редакторы

Pages CMS ([app.pagescms.org](https://app.pagescms.org)) это бесплатная
облачная админка поверх репозитория. Своей базы контента у неё нет: каждое сохранение
становится коммитом в выбранную ветку.

## Подключение

1. Войти на app.pagescms.org через **Sign in with GitHub**.
2. Установить GitHub App на организацию `yk-volzanin-yar`, доступ
   **Only select repositories → yk-volzanin-yar**.
3. Открыть репозиторий и выбрать ветку **`dev`** в меню вверху слева.

## Редакторы

**Collaborators → Invite a collaborator** → email редактора. Редактор входит
по email, аккаунт GitHub ему не нужен. Он меняет контент и файлы, но не
настройки и не список редакторов.

В коммитах указывается имя редактора: «Добавлено: content/news/… (Имя)».

## Конфигурация `.pages.yml`

- Коллекция **Новости** → `content/news`, **Разделы «Информации»** →
  `content/info`. Подписи полей на русском, кнопки интерфейса английские.
- Медиа **Картинки и документы** → `public/uploads` (jpg, jpeg, png, webp, pdf).
  Имена файлов транслитерируются (`rename: safe`).
- Медиа **Старые файлы сайта** → `public/general`. Видны в меню Media, но поля
  выбирают файлы только из `public/uploads`.
- Переименование записей отключено: оно меняло бы имя файла, а не адрес раздела.
- Порядок пунктов раздела меняется перетаскиванием.

Изменения в `.pages.yml` действуют сразу после коммита в `dev`.

## Особенности

- Загрузка файла идёт отдельным коммитом. Новость с фото запускает деплой дважды.
- В превью CMS картинки из старых путей (`/general/...`) внутри текста статьи
  не отображаются. На сайте они работают.
- Сервис работает «как есть», без гарантий, и может закрыть доступ без
  уведомления. Контент от этого не пострадает: он остаётся файлами в
  репозитории, и его можно править на github.com.
- Исходники открыты (MIT): [github.com/hunvreus/pagescms](https://github.com/hunvreus/pagescms).
  При закрытии сервиса его можно развернуть у себя (нужны PostgreSQL, своё
  GitHub App и HTTPS), см. [Self-host](https://pagescms.org/docs/guides/installing/self-host/).

Документация: [pagescms.org/docs](https://pagescms.org/docs/).
