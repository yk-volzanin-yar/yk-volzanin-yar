# 8. Формат файлов контента

Файлы написаны в Markdown с YAML-заголовком между строками `---`. Их пишет Pages CMS,
но можно править вручную на github.com.

## Новость: `content/news/<дата>-<имя>.md`

```yaml
---
title: С 1 июля 2025 года в России выросли тарифы на услуги ЖКХ
date: 2025-07-09
images:
  - /uploads/foto.jpg
---
Текст новости в Markdown.
```

| Поле | Обязательно | Значение |
|---|---|---|
| `title` | да | заголовок |
| `date` | да | `ГГГГ-ММ-ДД`, реальная дата |
| `images` | нет | список путей к фото, выводятся под текстом |

Лента сортирует по `date`, новые сверху. Имя файла на порядок не влияет.

## Раздел: `content/info/<slug>.md`

```yaml
---
title: Общие сведения по МКД
slug: mkd
order: 4
items:
  - type: article
    title: Заголовок статьи
    body: |-
      Текст в Markdown, можно с картинкой:
      ![Насос](/uploads/nasos.png)
  - type: document
    title: Договор управления
    file: /uploads/dogovor.pdf
  - type: image
    title: Схема
    image: /uploads/shema.png
  - type: heading
    title: Строка без ссылки
---
```

| Поле | Обязательно | Значение |
|---|---|---|
| `title` | да | название в меню и на странице |
| `slug` | да | адрес `/info/<slug>`: `a-z`, `0-9`, `-`, уникальный |
| `order` | нет | место в меню; без него раздел идёт в конец |
| `items` | нет | список пунктов |

Типы пунктов:

| `type` | Поля | На сайте |
|---|---|---|
| `article` | `title`, `body` | раскрывается по клику |
| `document` | `title`, `file` | ссылка, открывается в новой вкладке |
| `image` | `title`, `image` | ссылка, открывается в новой вкладке |
| `heading` | `title` | строка текста |

## Пути к файлам

Пути начинаются с `/` и считаются от `public/`: `/uploads/a.pdf` означает
`public/uploads/a.pdf`. Внешние ссылки (`https://…`) разрешены и не проверяются.
