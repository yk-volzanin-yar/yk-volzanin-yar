## Найденное сверх чек-листа

- **Порядок пунктов** меняется перетаскиванием (drag-and-drop, есть и клавиатурный вариант).
- **Каждое сохранение — отдельный коммит.** Новость с фото даёт два push в ветку → два прогона деплоя. `concurrency` в workflow это переживает (выполнится последний), но в Actions будет больше записей.
- **Имя файла новости** — `2026-10-24-testovaya-novost-prototipa-cms.md` (дата + транслит заголовка). Раздела — `testovyj-razdel-prototipa.md`. Совпадение имени со `slug` не обязательно.
- **`body: |+`** — YAML сохраняет завершающие переводы строк. Парсер на сайте должен это переносить (обычный YAML-парсер переносит).
