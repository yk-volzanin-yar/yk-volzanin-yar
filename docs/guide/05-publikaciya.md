# 5. Проверить, что сайт обновился

После **Save** сайт обновляется сам. Обычно это занимает одну-три минуты.

1. Подождите 3 минуты.
2. Откройте [ук-волжанин-яр.рф](https://ук-волжанин-яр.рф).
3. Обновите страницу: на компьютере `Ctrl+F5` (на Mac `Cmd+Shift+R`), на
   телефоне потяните страницу вниз.
4. Проверьте изменение.

Новость с фото сохраняется в два шага (сначала фото, потом текст), поэтому
иногда сайт обновляется два раза подряд. Это нормально.

Если через 10 минут изменения нет, смотрите
[Если что-то пошло не так](06-problemy.md).
