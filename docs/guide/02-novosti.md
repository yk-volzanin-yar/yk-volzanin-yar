# 2. Новости

Новости показываются на главной странице сайта, новые сверху.

## Добавить новость

1. Слева нажмите **Новости**.
2. Справа вверху нажмите **Add an entry**.
3. Заполните поля:
   - **Заголовок**: название новости.
   - **Дата**: сегодняшняя дата уже стоит. Чтобы поставить другую, нажмите на
     поле и выберите день в календаре.
   - **Фотографии**: по желанию. Нажмите **Upload** и выберите фото на
     устройстве. Фото появятся под текстом новости.
   - **Текст новости**: сам текст.
4. Нажмите **Save** справа вверху.

Через одну-три минуты новость появится на сайте.

## Оформление текста

Над текстом при выделении слов появляется панель:

- **B**: жирный шрифт;
- *I*: курсив;
- Text, Heading 1, Heading 2: обычный текст или заголовок;
- Bulleted list: список с точками;
- Numbered list: нумерованный список;
- Link: ссылка на другой сайт.

Чтобы вставить фото прямо в текст, поставьте курсор на пустую строку,
наберите `/` и выберите **Image**.

## Исправить новость

1. Слева **Новости**.
2. Нажмите на заголовок нужной новости.
3. Исправьте и нажмите **Save**.

## Удалить новость

1. Слева **Новости**.
2. В строке новости нажмите **⋯** справа и выберите **Delete**.
3. Подтвердите удаление.

Удалённую новость можно вернуть только через администратора.
