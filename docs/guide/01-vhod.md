# 1. Вход в админку

Адрес админки: **https://app.pagescms.org**

Сохраните его в закладках браузера. Админка работает на компьютере, планшете
и телефоне.

## Первый вход

Администратор присылает приглашение на вашу почту.

1. Откройте письмо от Pages CMS и нажмите ссылку в нём.
2. Если сайт попросит почту, введите ту, на которую пришло приглашение,
   и нажмите **Continue with email**.
3. Дальше следуйте письму, которое придёт на почту.

Аккаунт GitHub для этого не нужен. Кнопку **Sign in with GitHub** не нажимайте.

## Следующие входы

Откройте https://app.pagescms.org, введите почту и нажмите
**Continue with email**.

## Что вы увидите

Слева меню:

| Пункт меню | Что там |
|---|---|
| Новости | лента новостей на главной странице |
| Разделы «Информации» | разделы меню «Информация» на сайте |
| Картинки и документы | все загруженные фото и PDF |
| Старые файлы сайта | файлы, которые были на сайте раньше |

Вверху слева указана ветка `dev`. Это рабочая версия сайта, менять её не нужно.

Кнопки в админке на английском. Перевод основных:

| Кнопка | Значит |
|---|---|
| Add an entry | добавить запись |
| Edit | открыть для правки |
| Save | сохранить и опубликовать |
| Delete | удалить |
| Upload | загрузить файл с устройства |
| Select | выбрать уже загруженный файл |
| Add an item | добавить пункт в раздел |
| Remove | убрать |
