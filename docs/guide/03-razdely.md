# 3. Разделы «Информации»

На сайте в меню **Информация** есть разделы: «Общая информация», «Общие
собрания» и другие. В каждом разделе есть пункты.

Пункт бывает четырёх видов:

| Вид | Как выглядит на сайте |
|---|---|
| Статья (текст и картинки) | заголовок, по клику раскрывается текст |
| Документ (PDF) | заголовок-ссылка, открывает PDF |
| Картинка | заголовок-ссылка, открывает картинку |
| Подзаголовок (без файла) | просто строка текста |

## Добавить пункт в раздел

1. Слева **Разделы «Информации»**.
2. Нажмите на название раздела.
3. Внизу нажмите **Add an item** и выберите вид пункта.
4. Заполните **Заголовок** и:
   - для статьи заполните **Текст**;
   - для документа нажмите **Upload** у поля **Файл** и выберите PDF;
   - для картинки нажмите **Upload** у поля **Картинка**.
5. Нажмите **Save**.

## Поменять порядок пунктов

Наведите на пункт, зажмите значок **⋮⋮** слева и перетащите пункт выше или
ниже. Потом **Save**.

## Исправить или убрать пункт

Нажмите на пункт, чтобы раскрыть его. Исправьте поля. Чтобы убрать пункт,
нажмите кнопку справа от его названия и выберите удаление. Потом **Save**.

## Создать новый раздел

1. Слева **Разделы «Информации»**.
2. Нажмите **Add an entry**.
3. Заполните:
   - **Название раздела**: так он будет называться в меню.
   - **Адрес в ссылке**: короткое слово маленькими латинскими буквами,
     например `heating` или `tarify-2026`. Пробелы нельзя, вместо них дефис.
   - **Место в меню**: число. Сейчас разделы стоят под номерами с 1 по 6.
     Поставьте 7, чтобы новый раздел был последним.
4. Добавьте пункты (см. выше) и нажмите **Save**.

Раздел появится в меню «Информация» сам.

Если админка подсветила поле красным и пишет «Please fix the errors before
saving», исправьте подсвеченное поле. Чаще всего это русские буквы в адресе.
